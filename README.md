# Habit & Hydration Tracker

Лабораторная работа № 3. Небольшое Tkinter-приложение для отметки воды и привычек.

## Запуск

Нужен Python с установленным Tkinter. Запустите:

```bash
python main.py
```

## Возможности

- Пользователь задаёт собственную дневную цель по воде.
- Быстрые кнопки и ручной ввод добавляют выпитый объём.
- Прогресс показывается числом и полосой.
- Привычки можно добавить, отметить выполненными или удалить.
- Меню позволяет сбросить отметки за день, выбрать размер окна и включить или отключить его ручное изменение.
- Некорректный ввод и отсутствие выбранной привычки показываются в диалоговых окнах.

Данные хранятся только до закрытия приложения. Число цели — пользовательская настройка, не медицинская рекомендация.
